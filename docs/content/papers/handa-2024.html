Bayesian Preference Elicitation with Language Models

Handa, Gal, Pavlick, Goodman, Andreas, Tamkin & Li · arXiv, 2024

AI Agents Belief Elicitation

The specific contribution

OPEN (Optimal Preference Elicitation with Natural language) combines Bayesian Optimal Experimental Design (BOED) with language model question generation. Standard LM-based preference elicitation asks questions without tracking or modeling the user's posterior uncertainty. OPEN addresses this by using BOED to select the most informative next question given current uncertainty, while using an LM to phrase it naturally.

Key mechanism

ComponentWhat it does
Feature extractor (LM)Identifies relevant preference dimensions from domain description (e.g., "whether article is about science" for content recommendation)
BOED question selectorChooses next question to maximally reduce uncertainty about user preferences given current posterior
LM phrasingConverts BOED-selected question into natural language
Preference predictorStructured probabilistic model updated after each response

OPEN outperforms pure LM-based elicitation on preference prediction accuracy in content recommendation domains. The key advantage is explicit uncertainty tracking — the system knows what it doesn't know, and asks about that.

Connection to belief elicitation literature

OPEN is an AI system that implements elicitation-as-interface-scaffolding (Type 3 in this archive's taxonomy): the goal is not to measure a pre-existing preference but to help the user articulate and stabilize preferences through structured interaction. The Bayesian framework makes the constructive nature of elicitation explicit: as questions are asked, the system and user co-construct a preference representation.

Qualifications

Tested in content recommendation — a well-structured domain with clear feature spaces. Preference elicitation in less structured domains (ethical decisions, complex trade-offs) may not admit the same feature decomposition. The approach requires a structured feature space, which limits generality. BOED computation scales poorly with feature count.
