A Sparsity-Based Model of Bounded Rationality

Gabaix · , 2014

Attention & Salience

Developed a formal model of bounded rationality as optimal attention allocation. The agent faces a decision that depends on many variables but can only attend to a limited number of them. The agent optimally chooses which variables to attend to (and which to ignore) based on a cost-benefit analysis: the expected value of attending to a variable (how much it would change the decision) versus the cost of processing it.

The model generates three specific predictions: (1) Agents attend to the most important variables first and ignore less important ones, producing a "sparse" representation of the decision problem — hence "sparsity-based bounded rationality." (2) The set of attended variables changes with stakes: when stakes are low, agents attend to few variables and make more "biased" decisions; when stakes are high, they attend to more variables and decisions approximate full rationality. This produces the empirically observed pattern where many anomalies attenuate with higher stakes. (3) Inattention to specific variables produces predictable, directional errors — not random noise. For example, inattention to taxes produces systematic underweighting of taxes in purchasing decisions.

Unlike prospect theory (which models biased processing of all information), the sparsity model treats biases as rational responses to limited processing capacity. The agent isn't distorting probabilities or values — they're optimally choosing not to process some information. This connects bounded rationality to the formal tools of sparse estimation and information theory, making it analytically tractable rather than a collection of ad hoc heuristics.
