Attention, Memory, Salience & Cognitive Load

Interfaces compete for a limited attention budget. What the display makes prominent, the user treats as important — even when prominence does not track decision-relevance.

Assessment

Cognitive load theory (Sweller, 1988) distinguishes intrinsic load (task complexity), extraneous load (interface noise), and germane load (productive learning effort). Reducing extraneous load consistently improves decision quality across instructional and interface design contexts. What counts as "extraneous" depends on the task and the user's expertise — information that is noise for a novice may be essential for an expert.

Gabaix (2014) formalized bounded rationality as optimal attention allocation: agents attend to a sparse subset of available factors based on the expected value of attending to each. Bordalo, Gennaioli & Shleifer (2012) proposed salience theory, where attention is drawn to states where options differ most, producing choice anomalies that look like probability weighting but arise from attention instead.

In human-AI interaction, the accept rate for AI recommendations is typically ~80% across studies (Bansal et al., 2021). This is consistent with anchoring: once the user sees the AI's output, their subsequent judgment shifts toward it. Buçinca et al. (2021) reduced this by having users commit to an initial judgment before seeing the AI's recommendation, bringing agreement with incorrect AI from 69% to 52%.

Key claims

strong canonical Reducing extraneous cognitive load consistently improves decision quality.
Support
Cognitive load theory (Sweller, 1988). The principle is well-established across instructional and interface design.
Qualification
What counts as 'extraneous' depends on the task and user expertise. Information extraneous for a novice may be essential for an expert.
Verdict: The principle is sound. The difficulty is application: identifying which information is extraneous requires understanding both the task and the user.
mixed debated Salience-based accounts have design implications that diverge from probability-weighting accounts.
Support
Bordalo et al. (2012): overweight states where options differ most. Gabaix (2014): sparsity-based attention allocation.
Qualification
Empirically distinguishing salience effects from probability weighting in real interfaces is difficult. Both predict the same direction for many effects.
Verdict: The salience account has more actionable design implications but a shorter empirical track record.

Design implications grounded in evidence

AI recommendation accept rates run ~80% regardless of correctness. Bansal et al. (2021) found this across two tasks. The primary mechanism is anchoring: once the user sees the AI's output, their judgment shifts toward it. Buçinca et al. (2021) showed that forcing the user to commit before seeing the AI reduced agreement with incorrect predictions from 69% to 52%. Practical implementation: for high-stakes decisions, present the problem to the user first, collect their initial judgment, then show the AI's recommendation and flag any disagreement.

Cognitive forcing adds ~50% more time per decision. The Buçinca et al. (2021) experiments measured completion times. This overhead makes cognitive forcing impractical for high-volume, low-stakes decisions (content moderation, spam filtering, data entry) but appropriate for low-volume, high-stakes ones (medical diagnosis, loan approval, safety inspection). The design decision is whether the stakes justify the cognitive cost — a cost-benefit calculation, not a universal recommendation.

Explanation length is a double-edged sword. Vasconcelos et al. (2023) showed explanation engagement follows a cost-benefit function: when evaluation effort is low, explanations reduce overreliance; when effort is high, they are ignored or anchor the user further. The design implication: for any given explanation, estimate how long it takes a user to evaluate, and compare that to the decision stakes. If the evaluation cost exceeds the stakes, the explanation will not be used constructively.
