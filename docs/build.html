Build & Contribute

This page is for maintainers. It covers the repo structure, paper digest schema, build pipeline, and how to add new content. If you're here to read research, start here instead.

Project Structure

├── content/
│   ├── topics/         # One Markdown file per research stream
│   └── papers/         # One Markdown file per paper digest
├── data/
│   ├── papers.yaml    # Master paper registry (metadata + tags)
│   └── streams.yaml   # Stream definitions and relationships
├── docs/              # GitHub Pages static site (generated)
├── scripts/           # Build, add-paper, fetch-frontier tools
├── prompts/           # LLM prompt templates for paper processing
├── schemas/           # JSON schema for data validation
└── configs/           # Site and pipeline configuration

Quick Start

# Install dependencies
pip install -r requirements.txt

# Build the static site from content/
python scripts/build_site.py

# Add a new paper (creates a template)
python scripts/add_paper.py --id author-year

# Generate a digest from a PDF (LLM-assisted, requires API key)
python scripts/digest_paper.py --pdf path/to/paper.pdf --stream utility-decision-quality

# Scan arXiv for recent frontier papers in a stream
python scripts/fetch_frontier.py --stream agents-as-advisors --months 3

Paper Digest Format

Every paper gets a structured digest in YAML+Markdown with consistent fields: one-liner, core contribution, key concepts (with descriptions), methodology, limitations, legacy/influence, and optional personal reading notes.

Papers are tagged by stream and epistemic status: settled (robust, replicated, widely accepted), contested (active disagreement or important qualifications), or frontier (recent, promising, not yet replicated or integrated).

Each paper verdict should answer: What did this paper actually add? What would break if it were wrong? What later work weakened it? Should a new researcher still read it?

Epistemic Status Tags

TagMeaningExample
SettledRobust finding, widely replicated, part of the field's working knowledgeOverconfidence in confidence intervals; frequency advantage in Bayesian reasoning
ContestedActive debate, important qualifications, or competing explanationsWhether overconfidence is a bias or a statistical artifact; probability weighting vs. salience
FrontierRecent, promising, not yet replicated or fully integratedCognitive uncertainty as a unified explanation; AI-mediated elicitation

Adding a Paper

Run python scripts/add_paper.py --id author-year to scaffold a new paper digest from the template. Fill in the digest fields, add the entry to data/papers.yaml, and run python scripts/build_site.py to regenerate the site.

For LLM-assisted digestion: python scripts/digest_paper.py --pdf path/to/paper.pdf --stream stream-id generates a draft digest from a PDF. The draft needs human review — treat it as a starting point, not a finished product.

Website

The archive is published as a static site via GitHub Pages from the docs/ directory. To deploy: push to GitHub, enable GitHub Pages on the docs/ folder.
